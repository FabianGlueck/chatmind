# M17: Editing cards, by hand and with the model — Implementation Plan

> **For agentic workers:** implement task by task, TDD, commit per task. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Every card (question, answer, note) can be edited in place — by hand in a Markdown textarea, or by telling the model what to change in an Edit mode of the composer, with a streamed preview the user accepts or discards.

**Architecture:** A pure `buildEditContext` in core (shared by browser meter and server). The server opens its existing `PUT /nodes/:id` to every role and adds `POST /nodes/:id/rewrite` (SSE, writes nothing). The web generalises `NoteEditor` → `NodeEditor` (panel + chat view), and gives the composer a Reply | Edit mode with an `EditPreview` box above it.

**Spec:** `docs/superpowers/specs/2026-10-04-chatmind-m17-edit-cards-design.md` (binding).
